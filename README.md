# OS Lab

Implementations of fundamental Operating Systems concepts and system programming.

## Lab Topics

- **Command Line**: Command-line arguments and basic C program structure.
- **System Calls**: Process creation and management (`fork`, `exec`, `wait`).
- **Shell Scripting**: Bash scripting for automation and system tasks.
- **IPC**: Communication via Ordinary Pipes, Named Pipes (FIFOs), and Shared Memory.
- **Threads**: Multithreading and concurrency using Pthreads.
- **Signals**: Signal handling and inter-process signaling.
- **Synchronization**: Concurrency control using Mutexes and Semaphores.
